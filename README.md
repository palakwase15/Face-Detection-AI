# 👁️ Face Detection System
Face detection using OpenCV

This project detects human faces in real-time using Python and OpenCV.

## 🔹 Features
- Real-time face detection
- Multiple face detection
- Uses Haar Cascade

## 🔹 Technologies
- Python
- OpenCV

## 🔹 Run
pip install opencv-python  
python face.py
